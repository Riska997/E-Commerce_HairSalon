# Eve & Steve Salon

A responsive unisex salon appointment-booking website
developed using PHP, MySQL, HTML, CSS, JavaScript,
and Bootstrap.

## Project Overview

Eve & Steve Salon is a web-based salon appointment
management project. It allows customers to explore
salon services, create accounts, and submit appointment
requests through a user-friendly website.

The project demonstrates full-stack web development,
database integration, authentication, responsive
design, and form processing.

## Features

- Responsive homepage with a salon image carousel
- Featured salon services
- Seven salon service categories
- Database-driven service catalogue
- Service descriptions and pricing
- Customer account registration
- Customer login and logout
- Appointment booking requests
- Customer appointment history and status tracking
- Contact form with database storage
- Responsive navigation and salon branding

## Local Development

The project requires PHP, MySQL/MariaDB, and Composer.

Local database credentials and private environment
settings are not included in this repository.

Configure the local environment and database connection
before starting the PHP development server.
